# Logos — plan de réalisation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Logos officiels des banques dans l'app, icône B1-a et écran de chargement, livrés en APK 1.2.0.

**Architecture:** Module pur `logos.ts` (correspondance nom → logo) alimenté par la liste Enable Banking déjà exposée par `bank/aspsps` ; `BankDot` affiche le logo ou la pastille de secours. L'icône part d'un SVG source converti en PNG par un script ; l'écran de chargement passe par le plugin `expo-splash-screen`.

**Tech Stack:** Expo SDK 58, React Native `Image`, `node --test`, `sharp` via `npx` (script hors app), `expo-splash-screen`.

**Spec:** `docs/superpowers/specs/2026-11-13-logos-design.md`

## Global Constraints

- Couleurs B1-a : fond `#0B0D10`, dégradé `#60A5FA` → `#A78BFA`, point `#A78BFA`.
- Jamais de logo de marque dessiné ou embarqué : uniquement les URL fournies par Enable Banking.
- Logo introuvable, réseau coupé ou image en erreur → pastille actuelle (`bankMeta`).
- `version` → **1.2.0** ; nouvel APK seulement après confirmation de l'utilisateur.
- `logos.ts` n'importe pas `supabase` (tests `node --test`).

## Review Focus

1. Nom avec accents/ponctuation différents (« Société Générale » vs « Societe Generale ») → même logo (test `logoFor`).
2. Nom manuel plus court que le nom Enable Banking (« Fortuneo » vs « Fortuneo Banque ») → logo trouvé (test).
3. Nom ambigu trop court (« B », « CE ») → pas de logo plutôt qu'un faux (test : préfixe minimum 4 caractères).
4. Liste Enable Banking indisponible → aucune erreur affichée, pastilles (chargement partagé qui renvoie `[]`).
5. Logo transparent en mode sombre → fond blanc arrondi sous l'image.

**Interfaces:**
- Produces (`logos.ts`) : `normalizeBank(name: string): string` (minuscules, sans accents, seulement `[a-z0-9]`) ; `logoFor(name: string, aspsps: { name: string; logo: string | null }[]): string | null` — exact, puis normalisé égal, puis l'un préfixe de l'autre si le plus court fait ≥ 4 caractères normalisés ; `null` sinon.
